3 · 当前请求指标 




TTFT—调用开始 → 首个非空文本 delta


生成速度—底层 predicted_per_second；不是 chunk/s


总耗时—请求开始 → 流结束


首字后耗时—首个文本 delta → 流结束


Prompt eval—底层口径；可能包含图像处理，不可直接相加


图像 token prefill—日志报告：图像 embedding 进入 LLM 的耗时，不是视觉编码


输出 token—底层计数；没有计数时不从字符数估算


Prompt / 缓存 token—底层 prompt_n / cache_n




这些指标可能重叠。Prompt eval 包含视觉编码和图文 prefill；视觉编码器的独立耗时当前 API 未暴露。日志时间线是主线程收到日志的时间，不是 GPU timestamp。缺失值显示“—”，不会用相减估算冒充独立阶段实测。
